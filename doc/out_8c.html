Detailed Description

Implémentation de l’écriture d’une ligne (writeLN).

Fournit l’implémentation de writeLN déclarée dans out.h. Se référer au contrat documenté dans le header pour le rôle des paramètres (paragraphe PG, indices [i..j], largeur M, et flux FILE*).

See also
justify.c, notamment la fonction setPG pour voir la manière dont les couples d’indices (i, j) sont produits lors de la reconstruction.

static int rebuff ( size_t  need)
inlinestatic

(Interne) Garantit que la capacité du tampon interne est ≥ need.

Parameters
needCapacité minimale requise (en octets).
Return values
1succès (tampon prêt à l’emploi, inchangé ou réalloué).
0échec (overflow de calcul ou échec de realloc).
  • Politique d’agrandissement simple par doublement (x2) à partir de 256 octets.
  • Prévention d’overflow : si next <= new_size, on considère un dépassement et on échoue.
  • Cette fonction ne renseigne pas errno explicitement.
Note
Utilisation interne par writeLN ; l’appelant gère le retour (0/1).
