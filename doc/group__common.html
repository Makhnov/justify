Variable Documentation

◆ SEP

unsigned char SEP[ASCII_SIZE]
extern

Table de classification des séparateurs (indexée par octet).

  • Taille : 256 entrées.
  • Convention : 0 = non-séparateur ; combinaison de bits (cf. enum) = séparateur.

Exemple (dans common.c) :

unsigned char SEP[BUFFER_SIZE] = {
[0x09] = SPACE, // '\t'
[0x20] = SPACE, // ' '
[0x0A] = EOL, // '\n'
[0x0D] = CR // '\r'
// le reste = 0
};
