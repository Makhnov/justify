Detailed Description

Module qui implémente l'algo principal de la DP. Nous avons choisi de le coder en itératif.

Implémentation :
  • allocation des tableaux J (coûts minimaux) et N (index de reconstruction) ;
  • boucle principale descendante sur i (dernier mot vers le premier) qui cherche le meilleur j tel que le rab ugly + J[j+1] est minimal ; ugly est égal à M moins la somme des mots, il est décrémenté à chaque itération de j (sauf la première) ; pour simuler un espace entre les mots On conserve le minimum ainsi que l'index j correspondant dans best et bestj.  *  * 
Optimisation :
  • on limite j à jmax, la borne supérieure du meilleur j trouvé à l'itération précédente (on évite ainsi des itérations inutiles)
  • on utilise une variable locale ugly pour éviter de recalculer M - width à chaque itération

Reconstruction et écriture :
On part de i=0, j = N[i]-1, et on applique i = j+1 jusqu'à la fin du paragraphe. A chaque étape on écrit la ligne i..j via writeLN (détaillée dans out.h).
Note
Le tableau cubes est indexable sur 0..M (nous l'avons pré-calculé dans le main).
