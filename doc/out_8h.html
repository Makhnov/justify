Detailed Description

Écriture d'une ligne justifiée dans un flux FILE*.

Ce module fournit la primitive publique writeLN pour écrire une ligne du paragraphe (mots i..j) justifiée sur la largeur M, avec répartition des espaces « au plus régulier » :

  • on place au moins un espace entre chaque paire de mots ;
  • on répartit le « rab » (M - somme_longueurs - nb_gaps) en ajoutant ⌊rab / gaps⌋ espaces à chaque inter-mot, puis 1 espace supplémentaire aux rab % gaps premiers inter-mots ;
  • la dernière ligne (j == n - 1) n’est pas forcée à M : on écrit des espaces simples entre les mots et on termine par ‘’
    '`.

L’implémentation utilise un tampon interne réutilisable (dans out.c) pour limiter les I/O fragmentées (fwrite).

Parameters

iIndice du premier mot de la ligne (inclus).
jIndice du dernier mot de la ligne (inclus).
MLargeur cible (nombre de colonnes).
outFlux de sortie (ouvert en écriture).
Precondition
  • pg != NULL, out != NULL.
  • 0 <= i <= j < pg->n.
  • La ligne tient dans M selon le DP en amont (l’appelant garantit la validité).
Postcondition
  • Écrit exactement j - i blocs d’espaces entre les mots.
  • Termine la ligne par un **‘’
    '`** unique.
Returns
1 en cas de succès ; 0 en cas d’erreur (allocation interne ou écriture).
Note
  • Cas « un seul mot » (i == j) : le mot est écrit suivi d’un ‘’
    '(pas de remplissage àM).
  • Les octets de mots sont recopiés tels quels depuis la zone mmap (encodage source).
  • La **dernière ligne** (j == n - 1) n’est **pas nécessairement** remplie jusqu’àM`.
Warning
  • Ici on fait confiance à l’appelant pour la validité des indices i et j (0 <= i <= j < n).
  • On suppose aussi que i et j sont bien contenus dans la largeur M (sumLen + gaps <= M).
