Detailed Description

Constantes, catégories de caractères et utilitaires communs.

Ce fichier déclare :

  • la taille standard de certains buffers (BUFFER_SIZE),
  • la liste des jeux de caractères acceptés (VALID_CHARSETS),
  • la table de classification des séparateurs SEP (indexée par octet ISO-8859-1),
  • les catégories de séparateurs (masques de bits) et les macros de test (is_SPACE, is_EOL, is_CR, is_CRLF, is_SEP).
Note
SEP est indexée par octet (ISO-8859-1). Les macros castent en (unsigned char) pour éviter les UB liées à la signature de char.
