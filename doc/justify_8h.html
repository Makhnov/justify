Detailed Description

Programmation dynamique d'un paragraphe + écriture des lignes.

Cette unité fournit l'implémentation DP dite « itérative » sur un paragraphe déjà tokenisé (voir PG). Le calcul du coût minimal utilise deux tableaux indexés de manière parallèle :

  • J[i] : coût minimal du sous-paragraphe commençant au mot i,
  • N[i] : index du premier mot de la ligne suivante (pour la reconstruction).

La reconstruction s'effectue à la volée, directement après la DP en appelant writeLN() pour chaque ligne déterminée (écriture dans le FILE* passé en argument). La norme renvoyée est J[0], i.e. par norme, on entend la somme des cubes du reliquat des lignes internes uniquement (on ne compte pas la dernière ligne), conformément au sujet.

Note
L’écriture de chaque ligne est déléguée à writeLN (out.h / out.c). Le tableau cubes contient les valeurs i^3 pour 0 ≤ i ≤ M.

Parameters
pgParagraphe (mots et longueurs) déjà construit (voir parse.h).
MLargeur de ligne (Mu). Sert de borne et pour l’indexation de cubes.
outFlux de sortie ouvert en écriture binaire/texte.
cubesTableau pré-calculé tel que cubes[x] = x^3 pour tout 0 ≤ x ≤ M.
Returns
La norme (uint32_t) du paragraphe justifié (coût minimal). Retourne 0 si pg==NULL, out==NULL, pg->n==0 ou en cas d’échec d’allocation.
Precondition
pg != NULL, out != NULL, M ≥ 0, pg->n ≥ 0, cubes indexable sur 0..M.
Postcondition
Le paragraphe est écrit dans out (une ligne par appel à writeLN).
Warning
En cas d’échec d’allocation interne, la fonction renvoie LLONG_MAX (même type que le « vrai » coût). L’appelant doit vérifier le retour et, le cas échéant, afficher un message d'erreur en utilisant errno (cf. main.c).
Note
Complexité :
  • Temps : O(n · L) où L est le nombre max de mots qui tiennent sur une ligne (depuis une position i), i.e. le plus grand L tel que Σ W[i..i+L-1] + (L-1) ≤ M. Pour un M fixé (cas de ce programme), L est borné par une constante ⇒ O(n).
  • Mémoire : O(n) pour les tableaux J et N.
