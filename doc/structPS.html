Detailed Description

Contexte de parsing : zone mmap + fenêtre courante de paragraphe.

  • fd : descripteur du fichier mappé (lecture ; fermé par psclose()).
  • M : largeur de ligne (Mu) utilisée pour refuser un mot > M.
  • base..end : délimitation de la zone mappée ; cur : curseur global.
  • para_s..para_e : fenêtre du paragraphe courant (mise à jour par nextPG()).
