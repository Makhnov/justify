Detailed Description

Vérifications sur le fichier d'entrée : taille du fichier, format, encodage, etc.

  • getSize : récupère la taille via fstat(). En cas d’échec ou taille nulle, écrit un message sur stderr et ferme fd.
  • fileBI : vérifie le charset avec file -bi -- <path> : redirection de la STDOUT du fils vers une pipe et de la STDERR vers une autre (erreurs dup2/execlp/file).
Note
VALID_CHARSETS (définie dans check.c) contient la liste blanche (ex. "iso-8859-1", "us-ascii").

Parameters

  • succès : contient la ligne brute renvoyée par file -bi.

Return values

0Erreur d’exécution ou charset invalide (dans ce cas, buffer décrit la cause du refus).
Precondition
path != NULL, buffer != NULL, s > 0.
Note
Implémentation (résumé) :
  • deux pipes : pipefd (capture STDOUT du fils) et pipe_err (capture STDERR du fils) ;
  • fils : dup2(pipefd[1], STDOUT_FILENO) et dup2(pipe_err[1], STDERR_FILENO), puis execlp("file","file","-bi","--",path,NULL) ; en cas d’échec dup2/execlp, écrit le message d’erreur sur STDERR (redirigée) et _exit(1) ;
  • père : lit STDOUT dans buffer (puis **ajoute ‘’\0'**),waitpid(); lit **STDERR** : si un message y est présent, il **remplace** @p buffer et retourne 0 ; sinon, siWEXITSTATUS(status) != 0: message générique et 0 ; sinon, vérifie @ref VALID_CHARSETS (viastrstr`) ; à défaut, messages dédiés (“inode”, “pas texte”, “pas ISO-8859-1”).
Warning
En cas de succès (retour 1), le contenu de buffer est la ligne file -bi telle que lue par le père, l’appelant peut l’ignorer.
